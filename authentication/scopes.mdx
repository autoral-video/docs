title: "Escopos"
description: "Permissões granulares aplicadas a cada token."
---

Cada token carrega uma lista fixa de escopos no formato `recurso:ação`. Cada endpoint exige um escopo específico, indicado no topo da página dele nesta referência.

## Como funcionam

- Quando você faz `GET /api/v1/courses`, o servidor exige `courses:read`.
- Quando você faz `POST /api/v1/leads`, o servidor exige `leads:write`.
- Faltou o escopo? **403 Forbidden** com `error.type = authorization_error`.

<Note>
  Ao criar o token, o painel também lista permissões que nenhum endpoint da API usa ainda (ex: `courses:write`, `classes:read`). Marcá-las não libera nada — esta página traz só os escopos com efeito na API.
</Note>

<Tip>
  Princípio do menor privilégio — emita tokens com o **mínimo** de escopos. Um token só de leitura vazado é menos perigoso que um com `students:write`.
</Tip>

## Lista completa

### Conteúdo

| Escopo | Permite |
|---|---|
| `courses:read` | Listar e ver cursos, listar módulos de um curso. |
| `modules:read` | Listar aulas de um módulo. |
| `lessons:read` | Ver detalhes de uma aula. |
| `media-library:read` | Listar e ver arquivos da Biblioteca de Mídia. |
| `media-library:write` | Enviar e remover arquivos da Biblioteca de Mídia. |

### Alunos & Acesso

| Escopo | Permite |
|---|---|
| `students:read` | Listar e ver alunos. |
| `students:write` | Conceder/revogar acesso a cursos. |
| `access:read` | Listar matrículas (registros de Access). |
| `access:write` | Criar/remover matrículas diretamente. |

### Financeiro

| Escopo | Permite |
|---|---|
| `payments:read` | Listar e ver pagamentos. |
| `payments:refund` | Solicitar reembolso. **Sensível.** |
| `subscriptions:read` | Listar e ver assinaturas. |
| `subscriptions:cancel` | Cancelar assinaturas no gateway. **Sensível.** |

### Marketing

| Escopo | Permite |
|---|---|
| `coupons:read` | Listar e ver cupons. |
| `coupons:write` | Criar e remover cupons. |
| `leads:read` | Listar e ver leads. |
| `leads:write` | Criar leads (capturar de formulários externos). |
| `checkouts:read` | Listar e ver checkouts (somente leitura). |
| `quiz-funnels:read` | Listar e ver quizzes de venda e suas estatísticas. |
| `quiz-funnels:write` | Criar, atualizar, publicar e remover quizzes de venda. |

### Catálogo (produtos & ofertas)

| Escopo | Permite |
|---|---|
| `products:read` | Listar e ver produtos. |
| `products:write` | Criar e remover produtos (remover um produto remove as ofertas dele). |
| `offers:read` | Listar e ver ofertas (preços e planos de cobrança). |
| `offers:write` | Criar e remover ofertas. |

### Conta & Integrações

| Escopo | Permite |
|---|---|
| `certificates:read` | Listar e ver certificados emitidos. |
| `questions:read` | Listar e ver perguntas em aulas. |
| `webhooks:read` | Listar e ver webhooks outgoing. |
| `webhooks:write` | Criar e remover webhooks. |
| `pages:read` | Listar e ver páginas públicas (termos, landing pages). |
| `pages:write` | Criar, atualizar, publicar e remover páginas públicas. |

## Combinações comuns

<AccordionGroup>
  <Accordion title="Read-only (dashboard externo)">
    `courses:read`, `modules:read`, `lessons:read`, `students:read`, `payments:read`, `subscriptions:read`, `coupons:read`, `leads:read`, `checkouts:read`, `products:read`, `offers:read`, `certificates:read`
  </Accordion>

  <Accordion title="Integração de matrícula (n8n/Zapier)">
    `students:read`, `students:write`, `courses:read`
  </Accordion>

  <Accordion title="Captura de leads (form externo)">
    `leads:write`, `checkouts:read`
  </Accordion>

  <Accordion title="Montar catálogo (produtos e ofertas)">
    `courses:read`, `products:read`, `products:write`, `offers:read`, `offers:write`
  </Accordion>

  <Accordion title="Gestão financeira">
    `payments:read`, `payments:refund`, `subscriptions:read`, `subscriptions:cancel`
  </Accordion>

  <Accordion title="Gerar quizzes de venda (IA/automação)">
    `quiz-funnels:write`, `quiz-funnels:read`, `checkouts:read`
  </Accordion>

  <Accordion title="Publicar páginas (CMS/IA/automação)">
    `pages:read`, `pages:write`
  </Accordion>

  <Accordion title="Provisionar webhooks programaticamente">
    `webhooks:read`, `webhooks:write`
  </Accordion>
</AccordionGroup>

## Validando escopos do token atual

```bash
curl https://seu-dominio/api/v1/me \
  -H "Authorization: Bearer aut_..."
```

```json
{
  "data": {
    "token": {
      "abilities": ["courses:read", "students:write"]
    }
  }
}
```

<Warning>
  Mudou os escopos necessários da sua integração? Você precisa **criar um novo token** — escopos não são editáveis após a emissão.
</Warning>
