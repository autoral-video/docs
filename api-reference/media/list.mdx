---
title: "Listar mídias"
api: "GET /v1/media"
description: "Lista paginada (length-aware) dos arquivos da Biblioteca de Mídia."
---

**Escopo:** `media-library:read`
**Plano:** exige Biblioteca de Mídia no plano (senão **403** `plan_feature_unavailable`).

## Query params

<ParamField query="per_page" type="integer" default="25">1-100.</ParamField>
<ParamField query="page" type="integer" default="1">Página.</ParamField>
<ParamField query="kind" type="string">Filtra por tipo: `image`, `document` ou `audio`.</ParamField>
<ParamField query="folder_id" type="integer">Filtra por pasta.</ParamField>
<ParamField query="search" type="string">Busca parcial no nome do arquivo.</ParamField>

## Response

<ResponseField name="data[].id" type="integer">ID.</ResponseField>
<ResponseField name="data[].name" type="string">Nome original do arquivo.</ResponseField>
<ResponseField name="data[].kind" type="string">`image`, `document` ou `audio`.</ResponseField>
<ResponseField name="data[].mime_type" type="string">MIME type.</ResponseField>
<ResponseField name="data[].size" type="integer">Tamanho em bytes.</ResponseField>
<ResponseField name="data[].url" type="string">URL pública do arquivo.</ResponseField>
<ResponseField name="data[].folder_id" type="integer|null">Pasta.</ResponseField>
<ResponseField name="data[].alt_text" type="string|null">Texto alternativo.</ResponseField>
<ResponseField name="data[].width" type="integer|null">Largura em px (imagens).</ResponseField>
<ResponseField name="data[].height" type="integer|null">Altura em px (imagens).</ResponseField>
<ResponseField name="data[].duration" type="number|null">Duração em segundos (áudios).</ResponseField>
<ResponseField name="data[].tags" type="string[]">Nomes das tags.</ResponseField>
<ResponseField name="data[].created_at" type="string">ISO 8601.</ResponseField>
