---
title: "Remover mídia"
api: "DELETE /v1/media/{media}"
description: "Apaga um arquivo da Biblioteca de Mídia."
---

**Escopo:** `media-library:write`

<Warning>
  Remoção **definitiva**: o arquivo sai do storage e o registro é apagado. Páginas que usam a URL deixam de exibir o arquivo.
</Warning>

<ParamField path="media" type="integer" required>ID.</ParamField>

<RequestExample>
```bash cURL
curl -X DELETE https://seu-dominio/api/v1/media/42 \
  -H "Authorization: Bearer aut_..."
```
</RequestExample>

<ResponseExample>
```http 204 No Content
```
</ResponseExample>
