---
title: "Detalhes da página"
api: "GET /v1/pages/{page}"
description: "Retorna a página com o HTML completo do conteúdo."
---

**Escopo:** `pages:read`

<ParamField path="page" type="integer" required>ID da página.</ParamField>

## Response

Mesmos campos da [listagem](/api-reference/pages/list), mais:

<ResponseField name="data.content" type="string|null">
  HTML **cru**, como foi salvo: as variáveis (`{{site_name}}`, `{{year}}`…) aparecem sem substituição. A troca pelos valores reais acontece só na página pública.
</ResponseField>

<RequestExample>
```bash cURL
curl https://seu-dominio/api/v1/pages/4 \
  -H "Authorization: Bearer aut_..."
```
</RequestExample>
