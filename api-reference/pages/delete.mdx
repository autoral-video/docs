---
title: "Remover página"
api: "DELETE /v1/pages/{page}"
description: "Remove a página definitivamente."
---

**Escopo:** `pages:write`

O link público para de responder na hora (`404`). A remoção é **definitiva**: o slug fica livre para uma página nova.

<Warning>
  Se a página removida era a inicial do domínio (`is_homepage`), a raiz do domínio volta a redirecionar para o login.
</Warning>

<ParamField path="page" type="integer" required>ID da página.</ParamField>

<RequestExample>
```bash cURL
curl -X DELETE https://seu-dominio/api/v1/pages/4 \
  -H "Authorization: Bearer aut_..."
```
</RequestExample>

<ResponseExample>
```http 204 No Content
```
</ResponseExample>
